# Security

Please report security issues with the GWIX MCP server or API privately to **security@gwix.ai**. Do not open a public issue.

Include the endpoint, the steps to reproduce, and what you observed. We will acknowledge your report and keep you updated until it is resolved.

This repository holds configuration files only. The GWIX service itself runs at https://api.gwix.ai and is governed by the [GWIX Terms of Use](https://gwix.ai/terms).
